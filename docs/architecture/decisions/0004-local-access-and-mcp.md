# ADR 0004 การเข้าถึง API ในเครื่อง ช่องทาง MCP และการบังคับ agent_export

**สถานะ** รับรองแล้ว · ผู้ตัดสินใจคือ Product owner + Tech lead · เสนอ 7 พฤศจิกายน 2026 · เจ้าของเลือกทางเลือกทั้งสามข้อใน [Issue #16](https://github.com/Freshair129/paiya/issues/16) และรับรองตัวเอกสาร 8 พฤศจิกายน 2026 ([Issue #48 ข้อ E1](https://github.com/Freshair129/paiya/issues/48#issuecomment-6712472610))
**เกี่ยวข้อง** [SRS ข้อ 6](../../requirements/SRS.md) · [SPEC ข้อ 6](../SPEC.md) · [สัญญา Collector และ API](../contracts/collector-and-query.md) · [ADR 0003](0003-dev-tooling.md)

## โจทย์

SRS ข้อ 6 กำหนดว่า PWA ใช้ session ที่ตรวจสิทธิ์กับ API และ MCP ใช้ credential แบบอ่านอย่างเดียว แต่ยังไม่มีสัญญาว่าคำขอหนึ่งได้สิทธิ์อ่าน grant ชุดใด MCP เรียก API อย่างไร และ `agent_export` ถูกตรวจที่จุดใด งาน A5 (หน้ามือถือ) และ A6 (MCP) ต้องใช้คำตอบนี้

## ข้อตัดสิน

| เรื่อง | ทางที่เลือก | ทางที่ไม่เลือก |
|---|---|---|
| Q1 การยืนยันตัวตนของ HTTP API | API ผูกเฉพาะ `127.0.0.1` มี session ของเจ้าของเครื่องหนึ่งชุด session นี้อ่านได้ทุก grant ที่มี `read` และยังไม่เพิกถอนหรือหมดอายุ การเปิดให้เครื่องอื่นใน LAN ใช้ได้ต้องออก ADR ใหม่ที่เพิ่ม HTTPS และการจับคู่อุปกรณ์ | token แยกตามโปรแกรม (ต้องมีงานออก/เพิกถอน token ซึ่งเป็นงานความเสี่ยงสูง) และระบบบัญชีผู้ใช้เต็มรูปแบบ (นอกขอบเขต MVP) |
| Q2 ช่องทางของ MCP | MCP stdio server เรียก read service ชุดเดียวกับ API ภายใน process ไม่ผ่าน HTTP การตรวจขอบเขตทั้งหมดอยู่ใน service layer | MCP เป็น HTTP client ของ API (ต้องใช้ token แยกและแปลง error ซ้ำ) |
| Q3 จุดบังคับ `agent_export` | ตรวจในทางอ่านของ MCP เท่านั้น MCP server ตั้งปลายทางเป็น `local` (ค่าเริ่มต้น) หรือ `external:<name>` ทุกการอ่านผ่าน MCP ใช้เฉพาะ grant ที่มี `read` และเมื่อปลายทางไม่ใช่ `local` ต้องมี `agent_export` ที่ครอบคลุมปลายทางนั้น การอ่านผ่าน PWA ไม่ใช้ค่านี้ | ให้ client ส่งปลายทางมากับแต่ละคำสั่ง (client ประกาศเองจึงไม่น่าเชื่อถือ) |

## กติกาที่ตามมา

- read service รับ context ที่มีรายการ grant ที่อ่านได้ ไม่ใช่ grant เดียวแบบ fixture read context ของระยะ A การเปลี่ยนนี้ทำพร้อมงานที่เปิด session จริง
- รูปแบบค่า scope ใน `source_grants.scopes` สำหรับการส่งออกคือ `agent_export:local` และ `agent_export:external:<name>` ให้แก้ [แบบจำลองข้อมูล](../data-model.md) พร้อมงาน A6
- รายละเอียด session เช่น วิธีปลดล็อกครั้งแรก อายุ cookie, `HttpOnly`, `SameSite` และ CSRF ของคำขอที่เขียน ให้กำหนดในสัญญาก่อนเริ่มงานที่จัดการ session ซึ่งเป็นงานความเสี่ยงสูงตาม AGENTS.md และต้องได้อนุมัติใน Issue ก่อนเริ่ม

## เมื่อควรทบทวน

ทบทวนเมื่อมีผู้ใช้มากกว่าหนึ่งคนต่อเครื่อง ต้องการเปิดใช้จากมือถือผ่าน LAN หรือมีโปรแกรมภายนอกที่ต้องเรียก API โดยตรง
