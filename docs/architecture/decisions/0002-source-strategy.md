# ADR 0002 ช่องทางนำเข้าประกาศและการทดลองกับผู้ซื้อ

**สถานะ** เสนอเพื่อรับรองพร้อม PRD/SRS รุ่น 0.2 · ผู้ตัดสินใจคือ Product owner และ Tech lead
**ประวัติ** ร่างแรก 6 พฤศจิกายน 2026 เสนอสามทางเลือก ฉบับ 7 พฤศจิกายน 2026 ระบุขอบเขตที่เสนอ วิธีตัดสินจากผลทดลอง และส่วนที่ต้องพัฒนาก่อนเปิดใช้

## โจทย์ที่ต้องตัดสิน

ถ้าผู้ซื้อพบโพสต์ในกลุ่มที่ยังเก็บอัตโนมัติไม่ได้ เขายังควรเก็บข้อความ เปรียบเทียบราคา และย้อนดูคำยืนยันที่เคยเห็นได้ การเข้ากลุ่มหรือได้รับอนุญาตจากผู้ดูแลกลุ่มยังไม่ครบเงื่อนไขสำหรับเปิด Collector ของโครงการ ทางเลือกระยะ B ต้องมีทั้งสิทธิ์จากแพลตฟอร์มและสิทธิ์เข้าถึง/ใช้งานกลุ่มตามขอบเขตที่บันทึก [เงื่อนไขระยะ B](../SPEC.md) · [Meta Automated Data Collection Terms](https://www.facebook.com/legal/automated_data_collection_terms)

## ทางเลือกและผลต่อผู้ซื้อ

| ทางเลือก | สิ่งที่ผู้ซื้อได้ | เงื่อนไขและต้นทุน |
|---|---|---|
| รอแหล่ง Facebook ที่ได้รับอนุญาต | ค้นพบโพสต์ใหม่และตรวจโพสต์เดิมตามรอบ | กำหนดเปิดใช้ขึ้นกับสิทธิ์ของแต่ละแหล่งและผลทดสอบการแยก session |
| ผู้ใช้ส่งลิงก์พร้อมข้อความที่ใช้ได้ | รวมดีลหลายโพสต์ ดูหลักฐาน ตั้งรับและเทียบราคาได้บนเครื่องเดียว | ผู้ใช้ต้องพบโพสต์และส่งข้อมูลใหม่เอง ความสดขึ้นกับเวลาที่ส่ง |
| เพิ่มแหล่งข้อมูลอื่นที่อนุญาต | ทดลองค้นพบดีลอัตโนมัติจากช่องทางอื่น | ต้องพิสูจน์ว่ามีสินค้าและกลุ่มผู้ซื้อที่ต้องการก่อนสร้าง adapter |

## ขอบเขตที่เสนอสำหรับรุ่น 0.2

1. **ระยะ A** ใช้ fixture สังเคราะห์กำหนดคำตอบ ตรวจระบบกลางและแยกข้อมูลจำลองออกจากข้อมูลผู้ซื้อ
2. **ระยะ M** รับ permalink และข้อความที่ผู้ซื้อมีสิทธิ์ใช้ ให้ตรวจข้อมูลที่สกัดก่อนยืนยัน รับภาพเป็นหลักฐานเสริมเมื่อมีสิทธิ์เก็บสื่อ ส่งใหม่เพื่อเพิ่มรอบสังเกตได้ ระบบไม่เปิด permalink หรือค้น Facebook ระหว่างนำเข้า ข้อความที่ระบุตัวผู้พูดไม่ได้คงบทบาท unknown
3. **ระยะ B** คง live adapter หลัง feature flag ปิดเป็นค่าเริ่มต้น ใช้การทดลองหนึ่งกลุ่มก่อนเพิ่มได้ถึงห้ากลุ่มตามเกณฑ์เดิม การเปิดใช้ M ไม่เปิด B สิทธิ์นำเข้าในเครื่องไม่ให้สิทธิ์เก็บอัตโนมัติ
4. ใช้ observation v1 ที่มีอยู่กับ fixture/collector เดิม เอกสารฝั่งผู้ซื้อเสนอรูปแบบรุ่นถัดไปสำหรับ manual และราคาหลายองค์ประกอบ ให้พัฒนา schema ตัวตรวจและกรณีถอยหลังเข้ากันได้ก่อนเปิดรับข้อมูลรูปแบบใหม่ [สัญญาเดิม](../contracts/collector-and-query.md) · [สัญญาที่เสนอ](../contracts/buyer-workflows.md)

## วิธีตัดสินใจหลังทดลอง

Product owner เก็บเวลาเลือกดีลแบบเดิมเทียบกับป้ายยาและจำนวนผู้ซื้อที่กลับมาเพิ่มดีลที่สองเองในเจ็ดวัน รายงานจำนวนผู้เข้าร่วมและสาเหตุที่หยุดตั้งแต่ขั้นส่งประกาศ Tech lead รับผิดชอบตรวจสิทธิ์และความพร้อมของ B แยกกัน การอนุมัติ PR เอกสารไม่ได้ให้สิทธิ์เปิดแหล่งจริง OCR จะเข้ารอบออกแบบเมื่อพบว่าการคัดลอกข้อความเป็นเหตุสำคัญที่ทำให้ผู้ใช้ทำงานไม่จบ แล้วจึงตั้งเกณฑ์ความถูกต้องสำหรับตัวเลขไทย ราคาและบทบาทผู้พูดล่วงหน้า [เกณฑ์ตรวจรับ](../../quality/buyer-acceptance.md) · [แผนส่งมอบ](../../delivery/ROADMAP.md)
