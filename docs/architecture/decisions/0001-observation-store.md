# ADR 0001 เก็บประวัติการตรวจใน PostgreSQL และเก็บรูปบนเครื่อง

**วันที่** 6 พฤศจิกายน 2026
**สถานะ** ใช้เป็นแนวทางออกแบบ MVP การตรวจรับระบบยังรอการพัฒนาและทดสอบ

## บริบท

ผู้ซื้ออาจเห็นผู้สนใจพิมพ์ “จอง” แล้วมาเห็นผู้ขายแจ้งว่ากลับมาขายอีกครั้งในรอบถัดไป แอปและ Agent ต้องเปิดหลักฐานของแต่ละช่วงได้ แม้สถานะล่าสุดจะเปลี่ยนหรือโมเดลในเครื่องหยุดทำงาน

## การตัดสินใจ

ให้ PostgreSQL เก็บผลจากแต่ละรอบ รายการสินค้า เหตุการณ์เปลี่ยนสถานะ สิทธิ์อ่าน และข้อมูลกำกับหลักฐาน เก็บภาพครอปหรือลดขนาดในพื้นที่ถาวรบนเครื่อง ผูกด้วย evidence ID และ hash ของไฟล์ที่เก็บจริง หน้าแอปกับ MCP อ่านข้อมูลผ่าน API ที่ตรวจสิทธิ์เดียวกัน รอให้บันทึกผลการตรวจก่อนเพิ่มงานตีความเข้า Ollama

## ผลต่อการพัฒนา

- การเปิดโพสต์ไม่ได้ต้องสร้างผลตรวจของรอบนั้น โดยให้สถานะการขายล่าสุดชี้กลับไปยังหลักฐานเดิม
- การสำรองต้องจับคู่ SQL กับรายการไฟล์ภาพ การทดสอบกู้คืนต้องเปิดรูปจาก evidence ID และตรวจ hash ได้
- สถิติราคาตั้งขายอ่านจาก SQL ได้ในรุ่นแรก เมื่อพบคำถามที่ต้องเดินความสัมพันธ์หลายทอด ให้ทดสอบ GenesisBlockDB กับคำถามจริง พร้อมการสร้างกราฟใหม่จาก SQL และการลบข้อมูล ก่อนเพิ่มเป็นบริการในระบบ
