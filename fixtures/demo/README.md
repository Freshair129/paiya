# ชุดสาธิตมือถือสังเคราะห์

ไฟล์ในไดเรกทอรีนี้เป็นข้อมูลสังเคราะห์สำหรับ `python -m paiya.cli demo seed` เท่านั้น
รูปเป็น WebP ที่วาดจากรูปทรงและข้อความเรียบ ๆ และ permalink ทุกอันใช้ `example.invalid`.
ชุดนี้ใช้สาธิตหน้าจอ ไม่ใช่ golden หรือหลักฐานตรวจรับ.

`01-rtx3060-captured.json` และ `03-multi-item-reserved.json` อ้างถึงภาพใน `images/`;
`04-capture-failed.json` แสดงเหตุผลที่ไม่มีภาพ. `02-` และ `03-` เป็น observations
ของโพสต์หลายชิ้นเดียวกัน โดยผู้ขายยืนยันว่าชิ้น RTX 3060 ติดจอง.
