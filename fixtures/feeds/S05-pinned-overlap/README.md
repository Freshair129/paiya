# S05-pinned-overlap

ปักหมุดหนึ่งโพสต์ด้านบน รอบแรกอ่านจนฟีดหมด รอบสองมีโพสต์ใหม่สองชิ้นแล้วถึงโพสต์เดิมสามชิ้นติดกัน โพสต์ปักหมุดที่รู้จักแล้วไม่นับเป็น overlap

ข้อมูลสังเคราะห์ทั้งหมด เฉลยใน `expected.json` เขียนโดยคนตาม [สัญญาคิวค้นโพสต์](../../../docs/architecture/contracts/discovery-queue.md) ข้อ 4 ใช้ overlap 3 การ์ดและ 5 การ์ดต่อขั้นการเลื่อน **รอเจ้าของรีวิวเฉลย**
